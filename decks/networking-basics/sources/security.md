# Network security (self-written study notes)

- A firewall allows or blocks traffic using rules about addresses, ports and protocols.
- Default deny means traffic is blocked unless a rule explicitly allows it.
- A VPN creates an encrypted tunnel across an untrusted network.
- TLS gives a connection confidentiality, integrity and server authentication.
- Least privilege means giving an account only the access its task needs.
- A DMZ is a separate network segment that holds services exposed to the internet.
- Network segmentation limits how far an intruder can move sideways.
- Multi-factor authentication combines two or more of something you know, have or are.
- A port scan probes a host to find which ports accept connections.
- An intrusion detection system raises alerts, while an intrusion prevention system can also block traffic.
- WPA3 is the newer standard for securing Wi-Fi networks and replaces WPA2.
- A man-in-the-middle attacker sits between two parties and can read or change their traffic.
- Hashing a password with a unique salt stops identical passwords from producing identical hashes.
- A denial-of-service attack tries to make a service unavailable by overwhelming it.
